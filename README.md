# PURPLE UI - Премиальная библиотека компонентов


> Премиальная библиотека UI-компонентов с современными анимациями, кастомным курсором, 3D-эффектами и интерактивными взаимодействиями. ParticleBackground создает интерактивный фон с частицами, которые реагируют на движение мыши. CustomCursor — это стильный кастомный курсор с неоновым свечением.Разработано для взыскательных разработчиков.



## Технологический стек

### Core технологии

| Технология | Версия | Описание |
|------------|--------|----------|
| **React** | ^19.2.6 | Основная библиотека для построения пользовательских интерфейсов. Используются современные хуки (useState, useEffect, useRef) и компонентный подход. |
| **TypeScript** | ^5.5.4 | Статическая типизация для надежного и предсказуемого кода. Обеспечивает автодополнение и проверку типов во время разработки. |
| **Tailwind CSS** | ^3.4.4 | Утилитарный CSS-фреймворк для быстрой стилизации. Позволяет создавать кастомные дизайны без написания собственного CSS. |
| **Vite** | ^8.0.12 | Современный сборщик с мгновенной перезагрузкой (HMR). Обеспечивает быструю разработку и оптимизированную сборку. |

### Инструменты разработки

| Инструмент | Версия | Назначение |
|------------|--------|------------|
| **ESLint** | ^10.3.0 | Линтер для выявления и исправления ошибок в коде. Поддерживает React-хуки и современные правила. |
| **PostCSS** | ^8.4.38 | Трансформация CSS с помощью плагинов. Используется вместе с Autoprefixer и Tailwind. |
| **Autoprefixer** | ^10.4.19 | Автоматическое добавление вендорных префиксов для кроссбраузерной совместимости. |

### Зависимости

| Пакет | Версия | Назначение |
|-------|--------|------------|
| **lucide-react** | ^1.16.0 | Коллекция иконок для React. Используется в компонентах для визуального оформления. |

### Стилизация и анимации

| Технология | Описание |
|------------|----------|
| **CSS Animations** | Анимации на чистом CSS с использованием @keyframes и transition |
| **Glassmorphism** | Эффект стекла с backdrop-blur и полупрозрачностью |
| **Neon Glow** | Неоновое свечение с использованием box-shadow и text-shadow |
| **Gradients** | Градиентные переходы с background-image и gradient-анимациями |
| **Backdrop Filters** | Размытие фона через backdrop-blur и backdrop-filter |


## Архитектурные решения

## Компонентный подход	
Каждый компонент независим и переиспользуем
## Hooks API	
Использование кастомных хуков для логики (useToast)
## TypeScript Generics	Типизация пропсов с обобщениями

Этот стек обеспечивает высокую производительность, надежность и отличный опыт разработки для создания премиальных UI-компонентов.
